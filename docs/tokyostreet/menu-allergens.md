## この一覧の作り方（重複の除去ルール）

POS には運用の都合で**同じ料理が複数レコード**として登録されています。本一覧では以下を1品に統合しました。

| 重複の種類 | 例 | 統合方法 |
|---|---|---|
| **時間帯違い** | `Lunch Main` の Ginger-Pork €15.00 と `After 3PM&Sat&Sun Main` の Ginger-Pork €16.70 | **1品**にまとめ、Lunch / Dinner 両価格を併記 |
| **店舗違い** | Little Tokyo Kids Set (Hietalahati) / (Vallila) | **1品**にまとめ、提供店舗を列で表示 |
| **サイズ違い** | Kizan 8cl / 12cl / 16cl / 75cl | **1品**にまとめ、サイズ別価格を併記 |
| **カテゴリ未設定の孤児レコード** | `Ginger Pork Salad` ×2件（€17 / €15、category=null） | 既存の Salads と**同一品として統合** |

> **Lunch 価格の条件**: 平日 15:00 まで。味噌汁・コーヒー・紅茶が付きます。
> **Dinner 価格の条件**: 平日 15:00 以降、および土日終日。

## アレルゲン early summary（EU 14品目ベース）

Tokyo Street のメニュー全体で**該当が確認・推定される**アレルゲンは以下の通りです。

| アレルゲン | 記号 | 主な該当メニュー |
|---|---|---|
| **大豆 (Soybeans)** | 🫘 | 醤油・照り焼き・味噌を使うほぼ全料理、豆腐、枝豆 |
| **小麦・グルテン (Gluten)** | 🌾 | 麺類、餃子の皮、ビール、セイタン、醤油　※**唐揚げは非該当／醤油はGF版あり** |
| **ごま (Sesame)** | 🌰 | サラダ類、丼もの、ドレッシング |
| **魚 (Fish)** | 🐟 | サーモン各種、寿司、出汁（かつお） |
| **卵 (Eggs)** | 🥚 | マヨネーズ、餃子、ラーメンの麺・味玉 |
| **セロリ (Celery)** | 🥬 | サラダ類のドレッシング |
| **乳 (Milk)** | 🥛 | カルーアミルク |
| **亜硫酸塩 (Sulphites)** | 🍷 | 全ワイン |
| **甲殻類 (Crustaceans)** | 🦐 | 寿司のおまかせ（えび含む可能性） |

### 該当が想定されない品目
落花生、ナッツ類、乳（料理では未使用）、からし、ルピナス、軟体動物。
※ ただし**仕入先の加工品（餃子・ミートボール等）**については、製造元の原材料表で再確認が必要です。

### 🅶 グルテンフリー対応（店舗確認済み）

Tokyo Street では以下3つの対応により、**多くのメニューをグルテンフリーで提供可能**です。

| 対応 | 内容 |
|---|---|
| **① 唐揚げの衣** | **片栗粉のみ**を使用。小麦粉は不使用 |
| **② 揚げ油** | 小麦粉が混入しないよう**分離管理** |
| **③ 調味料** | **グルテンフリーの醤油・照り焼きだれを別途用意**（リクエストで変更可） |

| 1 Crispy Karaage & Fries Set | そのまま可（GFだれ指定） |
| French Fries（フライドポテト） | そのまま可 |

> 味付けは「GF醤油・GF照り焼きだれ」への変更で、幅広く対応できます。

## ⚠️ データ品質の指摘（要対応）

この一覧を作る過程で、POS 登録データに以下の問題を確認しました。

### 1. アレルゲン未登録が大多数
active 129件中、アレルゲン登録があるのは **35件のみ（27%）**。以下は明らかに該当があるのに**空欄**です。

- Karaage 系すべて（唐揚げ丼、唐揚げサラダ）→ 下味の醤油（大豆）※小麦は非該当
- 餃子すべて（1〜8個、€1.75〜€15.20）→ 皮に小麦
- Salmon Ramen → 魚・小麦・卵
- Ginger-Pork（丼・サラダ両方）→ 醤油（大豆）
- 寿司すべて → 魚・大豆
- ビール類 → 大麦グルテン
- Edamame → 大豆

> 🔴 **EU規則 1169/2011 では14品目の表示が義務**です。特に提供機会の多い餃子の小麦未登録、寿司の魚未登録は法令リスクがあります。

### 1-b. グルテンフリー対応が「どこにも登録されていない」
実店舗では **①片栗粉衣 ②分離管理した揚げ油 ③GF醤油・GF照り焼きだれ** という3段構えのグルテンフリー体制が整っているにもかかわらず、**POS DB にその情報が一切ありません**。

- `products.tags` … 全商品で空配列（`gluten-free` タグなし）
- `product_option_groups` … GF醤油／GFだれの選択肢が**未登録**（現状は口頭対応のみ）

> 🟡 **法令リスクの逆で、販売機会の損失**です。対応力があるのに顧客に見えていません。
>
> **推奨する最小実装**:
> 1. `products.tags` に `gluten-free` を付与（唐揚げ丼・唐揚げサラダ・French Fries 等）
> 2. `product_option_groups` に「ソース選択（通常 / グルテンフリー）」を €0 で追加
>    → キッチンへの伝達が KDS 経由で確実になり、口頭伝達ミスを防げます

### 2. Vegan Teriyaki Rice Bowl の小麦漏れ
セイタン（＝小麦グルテン）使用にもかかわらず、登録アレルゲンが `Soybean` のみ。
**ヴィーガン客＝グルテン回避客と誤認されやすい**ため、優先度が最も高い修正対象です。

### 3. `is_alcoholic` フラグの誤り
以下はアルコール商品ですが `is_alcoholic = false` になっています。

- Kirin Ichiban Draft Beer（生ビール）
- カクテル全16種（ハイボール、モヒート、ジムビーム、ジョニーウォーカー等）
- ワイン: Chardonnay, Umani Ronchi, Kaiken Rosé, D'Arenberg GSM, Prosecco
- 日本酒: Kido Ginjo, Kizan 全サイズ

> 正しく `true` なのは Asahi 33cl / Kirin 33cl / Sapporo 33cl / Riesling の4件のみ。
> 年齢確認やアルコール売上レポートに影響する可能性があります。

### 4. 寿司の価格逆転
`sushi-small` に €5.00 と €25.00 の2レコードが存在し、`sushi-large` は €10.00。
**小 €25 > 大 €10** となっており、いずれかが誤登録と思われます。

### 5. カテゴリ未設定の商品が22件
寿司、日本酒、ワイン（Chardonnay/Umani Ronchi）、ミートボール系などが `category = null`。
POS のカテゴリ画面に表示されず、検索でしか出せない状態です。

### 6. 命名規則の不統一
`chicken-meatballs-with-rice`、`kizan-(100%-pure-rice-wine),-8cl` のようなスラッグ形式の商品名が混在。
レシート・KDS での可読性が低下します。

### 7. 店舗未割当の商品
`product_availabilities` にレコードが無く、**どの店舗でも表示されない**商品:
Green Tea 330ml、Heineken Alcohol Free、kirin-non-alc-campaign、kirin-beer-campaign、chicken-meatballs-noodles

## 凡例

- `*` … POS未登録だが、料理内容から**該当が強く推定される**アレルゲン（要確認・要登録）
- `†` … 選択したオプションにより変動
- 🅶 … **グルテンフリー対応可**（店舗ヒアリングで確認済み）
- 唐揚げは**片栗粉のみ使用・揚げ油も分離管理**のため、小麦アレルゲンには該当しません
- **グルテンフリーの醤油・照り焼きだれを用意**しており、リクエストにより変更可能です（追加料金なし）
- 「両店」… Hietalahden Kauppahalli / Vallila の両方で提供
- 価格はすべて税込 (€, ALV 14% 食品 / 25.5% アルコール)
